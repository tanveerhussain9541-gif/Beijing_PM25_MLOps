# Beijing PM2.5 One-Hour-Ahead Forecasting
MSc AI/ML Semester III MLOps laboratory project.
## Objective
Predict PM2.5 concentration one hour ahead using past
and currently available air-quality observations.
## Dataset
UCI Beijing Multi-Site Air Quality; Aotizhongxin station.
Raw data is stored locally in data/raw/.
## Project structure
- src/: Python scripts- data/: raw and processed datasets (ignored by Git)- models/: trained model files (ignored by Git)- reports/: generated outputs- tests/: verification code
## Setup
Create and activate .venv, then install requirements.txt.
